# 🌸 Персональная программа здоровья Вики

> **Индивидуальный сервис здоровья, нутрициологии и медикаментозной поддержки**  
> Пациент: **Виктория**, 25 лет, г. Москва  
> Статус: 1 месяц после редукционной маммопластики (уменьшение груди)  
> Цели: Профилактика камней в почках и цистита, бережное снижение веса, устранение повышенной утомляемости и забывчивости, укрепление сосудистого тонуса при чувствительном психотипе.

---

## ⚡ Технологический стек
- **React 19 + TypeScript** — современный реактивный интерфейс без перезагрузки страниц.
- **Tailwind CSS v4** — быстрый, адаптивный дизайн (Mobile-first, оптимизация под iPhone, Safe-Area).
- **Vite 6** — молниеносная сборка (~500ms).
- **Lucide React** — контрастные медицинские и функциональные иконки.
- **LocalStorage State Sync** — сохранение прогресса выпитой воды, таблетницы и списка покупок на устройстве.

---

## 🚀 Основные модули и функционал

1. **Интерактивный дашборд**:
   - Трекер выпитой воды (цель 2 500 мл / 10 стаканов для защиты почек и вымывания оксалатов).
   - Интерактивная «Таблетница на сегодня» (Утро, День, Вечер) с галочками и напоминаниями.
   - Экспресс-протокол при первых признаках почечного или урологического дискомфорта.

2. **Меню питания на 7 дней + Мультяшный визуал и рецептура**:
   - Калораж: 1 650 – 1 750 ккал (плавное снижение веса без метаболического стресса).
   - Белок: 95–100 г (критично для ремоделирования рубцов и заживления дермы).
   - **Символичный/мультяшный органичный визуал**: каждое блюдо и каждый продукт имеют стилизованную иконку на мягком пастельном фоне.
   - **Интерактивное модальное окно рецепта**: при клике на картинку или название блюда открывается всплывающее окно с полным пошаговым процессом готовки, плашками используемых продуктов (с иконками и граммовками), временем приготовления, сложностью и секретом шефа для здоровья Вики.
   - Контроль оксалатов и солей (кабачки, цветная капуста, белая рыба, тыква, цитраты).
   - Профилактика цистита: клюквенные и брусничные некипяченые морсы без сахара.

3. **Аптечка и цены в Москве**:
   - D-Манноза (золотой стандарт профилактики цистита).
   - Канефрон Н (комплексная защита чашечно-лоханочной системы).
   - Магний Бисглицинат (хелат) — снятие сосудистых спазмов, успокоение нервной системы, предотвращение кристаллизации оксалата кальция.
   - Омега-3 1000 мг + Витамин D3 + Коэнзим Q10 (устранение «мозгового тумана», забывчивости и утомляемости).
   - Аскорутин + Венарус (укрепление капилляров, венозный отток).
   - Ester-C + Хелатный цинк (формирование эластичных рубцов).
   - Реальные цены в аптеках Москвы (Еаптека, Аптека.ру, Горздрав).

4. **Интерактивный чеклист покупок в супермаркетах Москвы**:
   - Разбивка по отделам (ВкусВилл, Перекресток, Самокат).
   - Чекбоксы для покупок со смартфона в магазине.

5. **Чек-ап диагностика (Анализы)**:
   - Ферритин (исключение латентной железодефицитной анемии после операции).
   - ТТГ и Т4 свободный (скрининг щитовидной железы).
   - Витамин 25(OH)D.
   - ОАМ с микроскопией осадка и УЗИ почек.

6. **Сосуды и реабилитация (1 месяц после операции)**:
   - Интерактивный таймер дыхания 4–7–8 для блуждающего нерва (антиспазм).
   - Лимфодренажные упражнения для голеней.
   - Памятка по компрессионному белью, силиконовым гелям (Дерматикс/Кело-коут) и ограничениям веса (до 2.5–3 кг).

## 💻 Локальный запуск

```bash
# 1. Перейти в папку проекта
cd troking-vika

# 2. Установить зависимости
npm install

# 3. Запустить локальный сервер для проверки
npm run dev

# 4. Сборка продакшн-версии
npm run build
```

## 🌐 Публикация в репозиторий GitHub (`troking/vika`)

```bash
# Инициализация репозитория (уже выполнена локально)
git init
git branch -M main
git add .
git commit -m "feat: initial release of Vika's personalized health web app"

# Привязка к вашему репозиторию на GitHub
git remote add origin https://github.com/troking/vika.git
# или через SSH:
# git remote add origin git@github.com:troking/vika.git

# Пуш в репозиторий
git push -u origin main
```

При пуше в ветку `main` благодаря настроенному `.github/workflows/deploy.yml` сайт автоматически развернется на **GitHub Pages** (в настройках репозитория `Settings -> Pages -> Build and deployment -> Source: GitHub Actions`).
